# 提示词优化功能设计

## 背景

用户希望在各个生图/改图页面添加提示词优化功能，通过独立配置的文本模型（LLM）自动将用户输入的提示词优化为适合 GPT Image 2.0 的高质量提示词。

## 目标

- 设置页支持独立配置文本模型（模型名称、Base URL、API Key）。
- 各生成页面提示词框右上角有灯泡按钮，点击后调用文本模型优化提示词。
- 优化过程有等待提示，完成后用户可选择采用或取消。
- 系统提示词根据页面类型（生图/编辑/参考图）自动选择对应模板。

## 方案

### 1. 设置页文本模型配置

- 在现有图片模型配置下方新增"文本模型配置"区域。
- 字段：`text_model`、`text_base_url`、`text_api_key`。
- Base URL 和 API Key 默认留空，用户自行填写。
- 存储在同一个 settings 记录中，`GET/POST /api/settings` 同步返回/接收。

### 2. 后端提示词优化接口

新增 `POST /api/optimize-prompt`：
- 请求体：`{ prompt, type }`，`type` 为 `generate` / `edit` / `reference` / `batch`。
- 从用户设置读取文本模型配置。
- 未配置文本模型时返回 400。
- 调用 OpenAI 兼容 `POST {base_url}/chat/completions`。
- 系统提示词根据 `type` 选择生图模板或编辑模板。
- 返回 `{ optimized: "..." }`。

### 3. 系统提示词

拆分为两套，reference 额外加编号说明：

- **生图模板**：自然语言描述，包含主体/环境/构图/视觉/文字/必须满足/避免结构。
- **编辑模板**：先保留再修改，包含必须保持不变/只修改/修改要求结构。
- **参考图模板**：编辑模板 + 参考图编号说明。

只输出优化后的提示词，不加解释。

### 4. 前端灯泡按钮

- 每个页面提示词框右上角加灯泡按钮。
- 点击：检查提示词非空，显示遮罩等待，调用接口。
- 成功：弹窗显示优化结果，"采用"替换原提示词，"取消"关闭。
- 失败：显示错误。
- 完成后恢复交互。

## 接口变更

新增：`POST /api/optimize-prompt`

扩展：`GET/POST /api/settings` 增加 `text_model`、`text_base_url`、`text_api_key` 字段。

## 测试策略

- 后端：`/api/optimize-prompt` 路由存在，系统提示词包含关键结构，未配置时返回 400。
- 前端：Settings.vue 包含文本模型配置区域，各页面包含灯泡按钮。
